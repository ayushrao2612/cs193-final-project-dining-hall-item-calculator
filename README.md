# Purdue dining hall dietary tracker

A Java app that fetches Purdue dining court menus and filters food options based on user preferences

## The Problem

Managing daily nutritional goals like calorie intake and protein targets can be challenging and time-consuming for students relying on campus dining hall app/website. This tool helps by filtering menu items based on student input.

## How It Works

The application retrieves live daily menu data from the Purdue Dining Court website and processes nutritional values for easy meal planning.

## Tech Stack

- **Language:** Java
- **Libraries:** Java HttpClient
- **External tools:** Purdue dining website


## Roadmap

- Allow users to select multiple food items to calculate totals
- Filter menu by dietary preferences (vegan, vegetarian)
- Picking a specific dining hall
